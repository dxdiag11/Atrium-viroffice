# PROMPT.md — Cave Quest Voting Board (Virtual Office Game UI)

## Objective

Create a **high-quality 2D game UI asset** for a **Virtual Office** game themed as a **fantasy cave dungeon quest board**. The asset is used as an in-game voting panel where office players vote for activities, events, or decisions.

The output must be a **transparent PNG** with **only the voting board UI** — no cave background, no characters, no environment.

---

# Art Direction

### Theme

Fantasy cave dungeon mixed with a cozy office game.

**Style Keywords**

- Cozy fantasy RPG.
- Dungeon quest board.
- Cartoon mobile game UI.
- Clash Royale / AFK Journey / MapleStory UI quality.
- Warm torchlight.
- Hand-painted textures.
- Cute but polished.
- Thick readable outlines.
- Premium casual game interface.

The board should feel like it belongs inside a magical cave where adventurers pick quests.

---

| Property | Value |

| Background | Transparent |
